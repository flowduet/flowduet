## 实现合同

- 仅 `@flowduet/form-create` 增量实现。`editingMode` 缺省 legacy；retained 显式启用，挂载后固定。新增三个 DTO 与只读状态/同步捕获 API，未改变 A/B 同步适配器、对象生命期、租约、候选/保存世代、文档或部署合同。
- 数值文本与普通日期手工输入由实例内缓冲拥有，按公开 componentRule 的原规则对象签发字段生命期；删除立即递归撤销，K 隐藏保留，旧回调不复活缓存。非法中间串不写业务值，但阻断整份候选；合法值须经 prop 回显与原规则确认，捕获前后核对 revision。
- 保留日历确认，动画窗口还读本实例公开 ARIA 展开状态；六类既有单值日期未编辑保真，非普通 date/自定义格式的手工编辑保留原文并明确 unsupported，不扩大 schema。
- FormManager 新增状态查询/转发；每次打开独立 key，关闭收尾先 not-ready、实际 closed 后才 null。X/遮罩/取消只请求关闭，须成功提交或明确放弃；所有等待后复验原会话/模式/版本。未知同 ID 替换或原位修改保留输入并阻断，不自动合并/覆盖。
- 仅自有关闭手势在 pointerdown/键盘前置检查，busy 时保留焦点并拒绝迟到 click；Tab 前往关闭控件另验。IME、内部弹层优先，Escape 不销毁 retained 表单；P3 未实现，不假报取消。父级强制卸载仍由宿主先确认。
- 缓存原文后的 change/失焦不再重复记账；普通 HTTP 宿主没有 randomUUID 时使用本地实例 key 退路，不把新增模式变成 legacy 的 secure-context 前提。

## 收尾两项P2级缺陷（不是后续P2文字切片）

1. 原Dialog的v-model隐式写共享显示状态，当前model=false可绕过明确放弃，旧组件未卸载时的迟到事件也能关新会话。补修改为受控modelValue和来源会话闭包；retained只请求关闭，legacy仍原样直接更新。旧事件回归在Vue重渲染前、旧组件仍isConnected时触发，并核emit次数，避免卸载后事件未执行的假覆盖。
2. 同ID同步重开而新子组件未挂载时，共享designerRef可指向旧子组件。补修按会话持有designer/ref回调，新会话not-ready，查询/收集只用当前会话；旧null只清匹配的原指针，不清新ref也不留旧ref。

新增4项正式回归均有RED/GREEN：除前述3项外，旧页头DOM迟到click原会读取新会话，现直接绑定渲染时的来源闭包；最终默认828/828，受影响30条UI重放通过。见[首批补修证据](evidence/b03-p1-2026-10-16/followup/README.md)和[页头补修证据](evidence/b03-p1-2026-10-16/header-followup/README.md)。
