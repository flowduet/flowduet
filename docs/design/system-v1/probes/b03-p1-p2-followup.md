## 修复边界

1. 第三方属性控件的等待以事件 token 隔离。聚焦原值由公开原生事件记录，输入恢复原值时等待一次 Vue 刷新后解除等待；非法原生 number 的 `badInput` 空串不算恢复。旧 change 的延迟回调不能清除随后输入。公开 `beforeRemoveRule` 在删除前记录仍连接的控件，delete/clear 的同步操作结束及 Vue 刷新后，仅回收本操作实际移除且 token 未变的控件；其他活控件的等待不变。K 隐藏及普通字段切换不清理等待，查询不清理状态。没有通过强制 blur、读取私有规则树或原文重建放行。
2. 数值/日期输入在任何外部通知前建立原文、预期值与等待门；即使 `1000 → 1e3`、`1 → 01` 或同日期，draftChange 同步订阅者也只能得到 blocked。同步订阅中若有更新输入或字段被撤销，旧 publish 失效。公开回显后保持字形并可捕获。
3. FormManager 将挂载时固定的 mode 传给每次打开的子编辑器。无编辑器时或成功关闭后修改 prop 均不切换实现；模式冲突时旧 commitPendingEdit 与按钮 save 路径也拒绝提交。legacy 默认及未发生模式冲突的原路径保留，不增加关闭确认或吞键；现有会话 key 与旧 Dialog 回调保护沿用。

公开 DTO、同步 EditorAdapter、A/B 控制器、对象生命期/租约、设计文档格式均不变。无新依赖，不改 core、designer、App、App 既有测试、依赖/lockfile 或 CI。
