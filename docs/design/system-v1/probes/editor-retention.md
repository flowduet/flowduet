## 待补证据与接口建议

异常/尚未序列化的第三方内部状态能否完整保存，目前只覆盖文本默认值及表单 options；不以这些结果保证所有字段编辑、拖拽中间态和异常状态。天然序列化失败、表单删除同 ID 后真实组件重挂、运行时内存预算仍需后续样例。身份策略已单独验证，但尚未接入真实多表单编辑器。

建议以按对象挂载作为保真参照，并继续验证哪些状态能够安全导出恢复；不能直接为节省 DOM 而改成自动提交 session。showDefaultForm 仅是探针候选接缝，尚未作为发布 API 核定。结构转换场景仍依赖独立结构修复。
