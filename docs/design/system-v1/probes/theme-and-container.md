# 主题隔离与容器验证

2026-10-15：本轮未重跑主题/容器全矩阵，下文仅作为历史证据；相关出口仍未通过，不能由结构或身份局部通过替代。

状态：仅映射 Element Plus 变量不足以实现整套深色；部分局部弹层路径已证明可行。完整 FormCreate 主题桥接仍需适配设计，不是“已证明无法实现”。

## 真实观察

- 深色 FormPreview 的选择器弹层在 body 下，主色为宿主默认 `#409eff`，背景白色；见 evidence/dark-form-dropdown.json。
- 直接控制的 Element Plus Select 使用局部挂载后，弹层位于深色实例内，主色为 `#a5b2ff`；见 dark-local-ep-dropdown.json。该选项不自动控制 FormCreate 内部弹层。
- FormCreate 自带预览对话框和日期弹层也脱离实例主题作用域；见 form-designer-preview-dialog.json、form-date-popup.json。
- 对两个既有实例交换浅深主题后，宿主对照输入的颜色与主色未变；见 theme-swap-host.json。仅证明所测宿主控件，不代表所有全局 CSS 或 Vue app 注册无影响。
- 去除探针自己的白底/按钮样式干扰后，真实设计器 `_fc-m-drag pc` 仍为白底，14px 字段标签颜色为 `rgb(196,206,222)`，测得对比度约 1.59:1；见 contrast-sample.json、dark-designer-1280.png。变量映射样例未达到规范目标，不应定稿。
- 日期输入按 Escape 关闭再按 Tab 能到达开关，并有可见轮廓；见 keyboard-focus.json/png。没有验证整个拖拽设计任务的键盘替代操作，不能声称完整可访问性通过。

## 容器观测

浅/深 × 紧凑/舒适，在 1440/1280/1024/900/768px 五个容器宽度采集了外层尺寸，共 20 个主题/密度/宽度观察。外层均未额外溢出，但这掩盖了内部画布被挤压：

| 容器 CSS px | 设计器中心区 CSS px | 实际表单内容宽度 CSS px |
| ----------- | ------------------- | ----------------------- |
| 768         | 108                 | 64                      |
| 900         | 240                 | 196                     |
| 1024        | 364                 | 320                     |
| 1280        | 620                 | 576                     |
| 1440        | 780                 | 736                     |

见 container-matrix.json 与 designer-center-widths.json。中心区表格采自舒适密度样例；不能用外层 scrollWidth 推导可用性。1280 可作为下一轮任务走查起点，尚不是已承诺的最小宽度。新工作台固定属性面板的 280/320/400px 组合尚未测量：当前正式组件仍是抽屉，需外置面板样机后才有有效的测量对象。

## 范围限制

八类字段已在真实设计器/渲染器中加载；本轮弹层深入检查了选择器、日期和设计器预览，并未穷尽每个属性配置菜单、颜色选择器与嵌套弹层。early/768/1440 截图及 dark-form-dropdown.png 是中间探针样式下的原始观察，用于空间/挂载取证；最终对比度结论使用去除探针背景干扰后的 1280 截图和 computed 样本。

实例的主题根作用域可行，直接 EP 弹层可用公开挂载配置；FormCreate 内部需要可维护的作用域桥接及自身颜色覆盖。完整方案、卸载清理、多版本兼容尚未证明，不预先接受浅色孤岛或取消隔离。Element Plus 依赖下限/peer 统一仍需另作方案。
