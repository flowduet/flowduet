## 接口建议与限制

保留保存请求序号、加载请求序号、文档世代和内容世代的区别；只有宿主确认成功才更新对应快照的保存状态。未来控制层应统一收集所有编辑缓冲，当前 ProbeHostController 仅承接真实 session 的读写与时序，不负责完整缓冲/候选规范化。
