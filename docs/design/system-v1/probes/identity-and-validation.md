候选 Registry 使用 documentEpoch + kind + id + lifetime；即时 remove 只删除匹配生命期，迟到通知不影响新对象；sync 在同 ID 元素引用变化时作废旧输入。只有受控命令显式声明逻辑延续时可续用 identity；此声明仍需调用方验证字段与基础版本相容，不可让任意宿主传一个 ID 就绕过冲突保护。

ValidationTracker 比较由调用者提供的有效内容与目标身份指纹，等价应用保持通过，规则或文档变更失效。它不实现通用 BPMN 语义 canonicalization；同对象原位外部字段变更需要上层候选读取/基础版本检查，不能由引用 identity 自动识别。保存状态在任务 5 的真实 session/宿主协议中另行验证。

结论：身份与校验版本分离的策略在所测输入下成立；受控操作通知完整性、真实缓冲存储和完整候选指纹仍需集成证据。结构转换端到端受生产缺陷阻断。
