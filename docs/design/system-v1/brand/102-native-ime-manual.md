## 判定口径

依据 [首批规格](../../../specs/element-plus-appearance.md) 的属性抽屉合同、输入生命周期、T03、T06、T07：

- T03 要求确定／取消及既有输入法提交保护保持；提交处理时组合仍有效，必须拒绝提交并走既有错误通道。
- T07 要求输入组合事件期间切换不丢字、不自动提交；真实 OS 中文输入法的步骤与实际结果单列，合成事件不能冒充 OS 实测。
- T06／输入生命周期要求外观切换保持输入、焦点与业务模型合同。不能用重建输入、清空内容或应用主动合成结束组合换取通过。

规格没有要求操作系统在每一次鼠标点击后都保持组合到提交处理时，也没有要求每个浏览器／输入法组合必须命中同一拒绝分支。以干净原生操作的实际事件顺序、完整内容和业务提交时点判定：

| 实际路径                                                         | 原生记录如何判定                                                                                                           | 合成回归承担的证据                                                 |
| ---------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| 提交时组合仍有效                                                 | 抽屉保持打开、模型不变、输入保留、出现既有提示；选词完成后显式确定才提交                                                   | 继续提供保护分支回归                                               |
| 原生组合先自然结束，再显式点击确定                               | 外观切换不丢内容、不自动写模型；显式点击后模型值与人工确认的上屏内容一致，可记为原生正常路径通过；拒绝分支登记为本次未触发 | 保护分支由既有组件测试和 Chromium 合成记录证明，不能标成原生已实测 |
| 组合仍有效却提交、切换丢字、重建导致内容丢失、外观切换自行写模型 | 停止验收，记录具体产品失败，另行诊断；不得用路径分类豁免                                                                   | 自动测试全绿不能推翻失败反例                                       |
| 出现合成输入／组合事件、刷新、控制连接或操作中页面隐藏           | 本轮证据不适用，停止并保留原物，不重试第二轮                                                                               | 不用合成回归替代该次原生缺口                                       |

“原生自然结束”需要操作来源与连续性证据支持。`isTrusted=true` 本身不证明物理按键来源，不能只按这一标记自动给出通过结论。无控制的独立 Chrome 配置、验收者对系统简体拼音与实际候选／上屏结果的确认、事件记录和可见结果共同支持原生路径。若来源仍不明，保持未验证。

本轮原生正常路径与既有保护分支回归可共同用于 T03／T07 的证据裁定，不要求为触发提示而制造非自然时序。两入口结果完整且没有重要缺陷后，实施方更新分项结论，维护者再判断整批门槛；不自动关票。

若组合在密度真正变化前已自然结束，也应将“原生组合期间切换”登记为本次未触发，不能仅因正常路径通过就写成该分支原生通过；该分支与明确标注的自动回归共同呈现后，由维护者判断整批门槛。

## 原人工路线的一次性准备方式（历史安排）

使用既有 Playground 的生产构建副本，构建完成后冻结资产并记录 SHA-256。服务器只监听 `127.0.0.1`，不提供浏览器控制接口、不连接 CDP／WebDriver／CUA，也不修改任何公开组件、表单定义或模型。

- [只读观察脚本](evidence/102-native-ime-manual-20261109/observe.js) 观察既有公开 DOM 的输入／组合／点击事件，记录输入对象标识、模型 change 计数、节点名称和预览试填 JSON。其浮层按钮只标记阶段与向本机交回结果，不操作应用控件；阶段进行中不点击浮层。
- [临时静态服务](evidence/102-native-ime-manual-20261109/serve.mjs) 在冻结的既有 HTML 中追加上述观察脚本，原产品 JS／CSS 字节保持。它是本次证据附件，不是新的长期演示宿主或通用测试平台，不新增依赖。
- Chrome 使用本次临时独立配置，扩展禁用，不带 remote-debugging 参数。用户自己启动并完成两条连续流程，代理在整个阶段只等待结果文件，不读取或控制浏览器。
- 单入口只允许开始一次。刷新后拒绝重新加载；记录遇合成输入、阶段期间隐藏或超过 800 条则停止。人工发现丢字、提前提交或流程无法完成时，使用停止按钮交回现状，不继续第二入口。结果文件只写入一次。

这些检查用于发现部分证据污染，不能证明浏览器绝无外部注入。若记录器漏掉事件、输入节点不可定位或用户不能确认实际输入法，记录无效或证据不足，不作通过裁定。
