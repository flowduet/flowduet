# FlowDuet 品牌与基础设计规范

版本：规范修订 R2，**已于 2026-11-03 经用户批准为品牌设计基线**。日期：2026-11-02。批准的是设计值与规则；第 7 章框架映射仍是源码核对后的候选，真实主题适配、实例隔离与公开配置接口均未验证，批准范围见[本轮决定](2026-11-02-decisions.md#用户批准)。已确认的品牌方向、舒适默认、R2 决定与交付边界见[本轮决定](2026-11-02-decisions.md)。

## 1. 视觉目标、两层结构与品牌使用

主要操作者为流程实施顾问。界面优先让配置对象、当前选择、缺失信息和操作结果清楚可辨；默认舒适密度，提供紧凑档用于高密度场景。

FlowDuet 是嵌入宿主系统的组件库，视觉分两层：

| 层次   | 消费场景                                      | 配色来源                                                 | 规则                                                                                                      |
| ------ | --------------------------------------------- | -------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| 品牌层 | 标志、社交卡、README、文档站、Playground 展示 | FlowDuet 品牌预设：靛蓝主色、珊瑚橙点缀                  | 完整表达品牌；标志母版不随宿主换色                                                                        |
| 组件层 | 嵌入宿主的完整设计界面与独立组件              | **默认跟随宿主**；可显式选用品牌预设或宿主种子定制（§6） | 跟随宿主的主色、中性色、字体与圆角；FlowDuet 风格由结构、空间、状态语义与节点类型表达，而不是强加品牌主色 |

组件层的珊瑚橙／宿主辅助色只用于圆点、细线等非文字点缀；带文字的标签使用中性色，任何辅助色都不表达错误、警告、待应用等状态。该分层承接 [ADR-0010](../../../adr/0010-integrated-designer-delivery.md) 第 4 条“通过统一规范与适配形成 FlowDuet 风格”：风格由统一规范承载，品牌主色降为可选预设；这是对该条表述的具体化，记录见[本轮决定](2026-11-02-decisions.md#r2-第-2-轮集中修订)。

沿用[一树两冠母版](../../../assets/logo/icon.svg)：靛蓝 `#2D3E97`、珊瑚橙 `#F76547`，圆心透底。不得挪动母版路径、填白圆心、改变比例或给标志换宿主色。真正修改母版仍走 [ADR-0008](../../../adr/0008-logo-visual-identity.md) 的原定流程。

候选使用规则：标志四周至少留出显示图形宽度的 1/4 净空；常规应用显示 24–32px 图形，小尺寸沿用现有 16/32px 资产并单独核对。深色背景可放入白色中性底板，底板属于承托区域而非标志一部分。样稿采用 30px 图形与 42px 底板；这些是本批候选值，不替代历史母版。

宿主可以使用自身品牌；独立组件不新增强制水印。宿主品牌替换不改变 FlowDuet 母版，也不推导新的许可限制。本批仅展示宿主配色对照，没有设计官网、宣传物料或完整工作台品牌区。

## 2. 设计变量的层级

| 层次     | 内容                                                       | 消费方式                             |
| -------- | ---------------------------------------------------------- | ------------------------------------ |
| 品牌常量 | 既定标志与双色                                             | 标志与品牌展示使用，不随宿主颜色重绘 |
| 基础值   | 字体、字号、间距、圆角、焦点、动效                         | 形成统一尺度，不逐控件随意定义       |
| 语义值   | 表面、文字、主操作、选择、焦点、错误、警告、成功、节点类型 | 各主题分别给值，组件按用途消费       |
| 配色来源 | 跟随宿主、FlowDuet 品牌预设、宿主种子定制                  | 决定主色与中性色从哪来，见 §6        |
| 密度值   | 控件高度、字段间距、面板及节点内边距                       | 两档与 EP size 对齐，见 §4           |
| 组件映射 | 按钮、输入、节点、分支、表单错误                           | 引用语义角色，不把所有颜色映射成主色 |

完整值在 [tokens.json](tokens.json)。该 JSON 是设计数据，结构和名称未成为 npm 公开配置合同。主色衍生角色与跟随宿主时的中性派生值由 [derive-palette.mjs](derive-palette.mjs) 按种子生成，不手改；运行 `node docs/design/system-v1/brand/derive-palette.mjs --check` 可校验派生值、对比度、节点类型色差与样稿快照。样稿将数据映射到自身根元素下的 `--fd-*` 变量，不能据此宣布产品已具备主题接口。

## 3. 色彩与状态

| 角色       | 浅色候选  | 深色候选  | 用法                             |
| ---------- | --------- | --------- | -------------------------------- |
| 画布       | `#F5F6FA` | `#141925` | 大面积背景                       |
| 表面       | `#FFFFFF` | `#1D2435` | 控件、配置区域、节点             |
| 正文       | `#20263D` | `#E9EDF7` | 主要内容                         |
| 次级文字   | `#565F76` | `#B7C0D5` | 说明、辅助配置                   |
| 主操作     | `#2D3E97` | `#A5BBFF` | 品牌预设主按钮；由种子派生       |
| 主操作前景 | `#FFFFFF` | `#171F3E` | 不把深色主按钮机械设成白字       |
| 选中墨色   | `#2D3E97` | `#A5BBFF` | primaryInk：选中边框、已选中文字 |
| 珊瑚橙点缀 | `#F76547` | `#F76547` | 仅非文字小点缀；不能默认配白字   |
| 审批类型   | `#3C4958` | `#CED9E5` | 低彩度类型标题；不随宿主换色     |
| 条件类型   | `#655284` | `#B098CD` | 分支标签；与警告、选中色分开     |
| 错误       | `#B4233A` | `#FF9DAE` | 阻断性错误文字、字段边界及原因   |
| 警告       | `#8C5C12` | `#F0C46B` | 可保存但需补全或检查的提醒       |
| 成功       | `#23714D` | `#81D5A6` | 已知成功结果及文字               |

表中主操作、前景与选中墨色为品牌预设值；跟随宿主或种子定制时按 §6 派生，其余角色由 FlowDuet 自有。主题不是直接反色：主操作、文字、底色、边界、焦点分别配对。交互边界使用 `controlBorder`，分组装饰使用较弱的 `border`；不能只靠低对比装饰线识别输入区域。

状态语义按对流程交付的影响区分：

| 状态   | 颜色与标识                    | 适用场景                                                                                                               |
| ------ | ----------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| 错误   | danger＋“!”＋原因文字         | 输入值非法、无法保存，或阻断导出／部署；对应“[合法可执行](../../../../GLOSSARY.md#引擎与适配)”承诺被破坏的情况         |
| 警告   | warning＋“!”＋原因文字        | [设计草稿](../../../../GLOSSARY.md#表单绑定)中尚未补全的配置（如“待完善：审批人未设置”）；草稿可以保存，提醒不等于阻断 |
| 成功   | success＋“✓”＋文字            | 已知成功的结果                                                                                                         |
| 待应用 | primaryInk 圆点＋文字         | 编辑状态，不承诺已经保存到宿主；不使用珊瑚橙或任何辅助色                                                               |
| 选中   | 2px primaryInk 边框＋“已选中” | 当前选择；不能只依赖颜色                                                                                               |

节点类型色采用低彩度，与高彩度的主色／选中色在彩度和明度上拉开：检查要求类型色与 `primary`、`primaryInk` 的 OKLab 距离不少于 0.08。该距离对 `tokens.json` 中已登记的预设是硬性检查（`--check` 失败即不交付）；宿主运行时提供的任意种子仍可能接近类型色，此时依靠边框粗细与“已选中”文字区分，只提示不拒绝。

候选检查目标：普通文字与其实际背景至少 4.5:1，识别交互边界、焦点、选中边框和连接线至少 3:1。检查三种配色来源 × 浅深主题；禁用态单列记录。跟随宿主时 EP 自身控件仍使用宿主原值（如默认主按钮白字 2.78:1），它们只登记为宿主继承信息，不计为 FlowDuet 自有角色通过或失败。通过这些设计检查不等于整个产品符合可访问性标准。

## 4. 字体、空间与两档密度

默认使用系统中文字体栈，不下载远程字体。字号以 px 记录为设计候选，不限制浏览器缩放。

| 层级         | 候选字号 | 使用规则                             |
| ------------ | -------- | ------------------------------------ |
| 样稿展示标题 | 30px     | 仅规范展示页，不直接推广到产品工具栏 |
| 区域标题     | 20px     | 三组样稿的章节标题                   |
| 片段标题     | 16px     | 表单、属性配置区标题                 |
| 正文         | 14px     | 两档密度都保留；默认行高 1.6         |
| 控件内文字   | 14／12px | 舒适／紧凑，随 EP default／small     |
| 字段标签     | 13px     | 清楚命名，必填有文本语义与标记       |
| 辅助说明     | 12px     | 不承载唯一的关键操作                 |

| 空间项       | 舒适（默认） | 紧凑    |
| ------------ | ------------ | ------- |
| 对应 EP size | `default`    | `small` |
| 控件高度     | 32px         | 24px    |
| 字段间距     | 16px         | 12px    |
| 面板内边距   | 24px         | 16px    |
| 节点内边距   | 16px         | 12px    |
| 同排控件间隔 | 12px         | 8px     |

两档控件高度与 Element Plus 2.14.6 的 `default`／`small`（32／24px）一致，使宿主自有 EP 控件与 FlowDuet 控件同屏时高度统一，适配时优先用 size 上下文而不逐控件覆盖高度。紧凑档控件内文字随 EP small 为 12px，正文、节点标题与字段标签不随之缩小。舒适默认沿用 Q3 决定。当前产品两种尺寸混用：FormCreate 管理区与工具条显式 `size="small"`，designer 节点抽屉与属性字段使用 EP default；真实适配统一到舒适默认会让 FormCreate 部分变高，须单独确认（见 §7.2）。

基础间距使用 4、8、12、16、20、24、32、48px。圆角在跟随宿主时读取宿主 `--el-border-radius-base`（EP 默认 4px），品牌预设为 8px。焦点线 2px、偏移 3px，避免被容器裁切。悬停过渡 120ms，减少动态效果偏好下关闭过渡；处理中样例使用静态进度符号与文字，不加入无限动画。

长节点名称自然换行；输入框内的长值允许原生光标滚动，不能把关键配置静默截断成省略号。窄屏样稿可以堆叠片段，便于阅读规范；这不新增手机完整编辑承诺。

## 5. 三组样稿与组件状态

| 组             | 本轮内容                                 | 适用状态                                         |
| -------------- | ---------------------------------------- | ------------------------------------------------ |
| 基础控件       | 主次按钮、输入、只读字段、提示           | 正常、悬停、焦点、禁用、错误、处理中、成功、警告 |
| 流程节点与分支 | 审批节点、条件分支、默认支路、长中文名称 | 正常、选中、待完善；连接线示意                   |
| 表单配置片段   | 字段预览、显示名称、输入提示、填写要求   | 必填、空白、错误、未添加字段、待应用提示         |

按钮基于主操作与前景配对；输入基于表面、正文、边界、焦点与错误；审批类型和条件类型保持独立语义，选中边框与“已选中”消费由当前主色派生的 `primaryInk`；“待完善”使用警告色；表单错误与基础输入使用同一套规则。样稿的“配色来源”可切换跟随宿主、品牌预设与青绿宿主种子三种来源。JSON 的 `componentMappings` 只列主要语义索引，不是样稿所有状态的完整变量消费清单；未列入不表示该组件不消费相应角色。框架的具体入口与待验证范围见第 7 章及 `framework-mapping.json`。

支持原生只读的文本控件保留焦点、选择与复制；禁用表示当前无法操作。单选、多选、下拉、开关等不能直接套用文本 readonly，未支持的只读呈现留待交互合同确认，不通过静默 disabled 或替换组件来改变行为。处理中同时显示文字和状态标识，真实请求的拒绝重入、取消和错误恢复未在本轮实现。

样稿操作只改变本页呈现与演示反馈。字段错误和成功提示为固定状态样例，不进行业务校验；流程连接线与节点点击不操作 BPMN 模型。适配 Element Plus、FormCreate、Vue Flow 时需另行核对真实 DOM、公开扩展点、焦点、弹层与组件版本。

## 6. 配色来源与宿主定制候选规则

保留主色、辅助色、字体、基础字号、圆角、密度、属性面板宽度的定制要求，但颜色不再要求宿主逐个提供角色值。组件层有三种配色来源：

| 来源                 | 谁选择                                | 主色与中性色                                                                            | 是否写入 `--el-*`        |
| -------------------- | ------------------------------------- | --------------------------------------------------------------------------------------- | ------------------------ |
| 跟随宿主（组件默认） | 默认，无需配置                        | 读取宿主 EP 变量；FlowDuet 只为自有组件派生 primaryInk、primarySoft、focus 及可读中性色 | 否；宿主 EP 控件保持原样 |
| FlowDuet 品牌预设    | 宿主显式选择；Playground 与文档站使用 | 由靛蓝、珊瑚橙种子派生                                                                  | 是，仅限组件实例范围     |
| 宿主种子定制         | 宿主显式提供种子色                    | 主色种子＋可选辅助色种子，按同一规则派生                                                | 是，仅限组件实例范围     |

跟随宿主时读取的变量：画布 `--el-bg-color-page`、表面 `--el-bg-color`、内嵌底与禁用底 `--el-fill-color-light`／`--el-disabled-bg-color`、正文 `--el-text-color-primary`、次级文字 `--el-text-color-regular`、装饰线 `--el-border-color-light`、禁用文字 `--el-disabled-text-color`、主色及按钮三态、字体 `--el-font-family`、圆角 `--el-border-radius-base`。EP 默认的 `--el-text-color-secondary`（#909399，对白底 3.08:1）、占位色（2.30:1）与输入边框（1.33:1）不满足本稿目标，FlowDuet 自有组件不消费它们，改用从正文向表面混合得到的 `muted`（≥4.5:1）与 `controlBorder`（≥3:1）。

派生规则（OKLCH，完整参数见 `tokens.json` 的 `derivation`）：

1. 浅色主题原样使用主色种子；深色主题保持色相，明度取 0.80，并在 sRGB 色域内尽量保留彩度。
2. 悬停、按下在主色明度上分别 −0.05／−0.10（深色 +0.05／−0.06）。
3. 主色前景在白色与同色相深墨色中取首个对主色三态均达 4.5:1 者。
4. `primaryInk` 从主色明度起向可读方向搜索，直至对表面、画布、内嵌底、primarySoft 与审批类型浅底均达 4.5:1，用于选中边框、选中文字与链接；`focus` 在主色达 3:1 时用主色，否则用 primaryInk。
5. 辅助色种子原样用于非文字点缀，墨色限制彩度后搜索可读明度；未提供时点缀退回中性色，不引入珊瑚橙。
6. 品牌预设与种子定制写入实例范围时，EP 的 `light-3/5/7/8/9`、`dark-2` 沿用 EP 混色规则生成（`tokens.json` 的 `epScale`）。

任何角色无法达标时，候选处理是拒绝该种子、回退跟随宿主并给出可读原因，不静默降低目标。错误、警告、成功与节点类型由 FlowDuet 自有，不随宿主主辅色替换。精确配置结构、覆盖优先级和错误通道待真实适配阶段审阅，不将本页规则自动施加给已有调用方。

| 项目         | 组件默认 / 品牌预设 / 青绿对照                    | 候选边界与非法值处理                                     |
| ------------ | ------------------------------------------------- | -------------------------------------------------------- |
| 主色种子     | 宿主 `--el-color-primary` / `#2D3E97` / `#0F6B65` | `#RRGGBB`；按上述规则派生并检查，失败时拒绝并回退        |
| 辅助色种子   | 无 / `#F76547` / `#E3B14F`                        | 可选；只做非文字点缀                                     |
| 字体         | 宿主 `--el-font-family` / 系统栈 / 中文字体栈     | 非空合法字体族列表；不可用字体由系统回退，不加载远程字体 |
| 基础字号     | 宿主 `--el-font-size-base` / 14 / 15px            | 建议 14–18px；标签及说明层级需随配置复核                 |
| 圆角         | 宿主 `--el-border-radius-base` / 8 / 4px          | 建议 0–12px；不挤压内容或焦点                            |
| 密度         | 舒适默认 / 可切紧凑                               | 两档枚举，对应 EP default／small                         |
| 属性面板宽度 | 360 / 360 / 400px                                 | 建议 320–440px，仍受容器与画布空间约束                   |

类型错误、非有限数值、超范围值的候选处理是拒绝该项、回退默认并提示原因；不能静默把任意值施加到布局。主题或密度枚举非法时同样回退默认并提示。这只是后续接口讨论输入；样稿使用固定预设，派生脚本只是设计检查工具，未实现产品配置校验器。

面板宽度在样稿中是上限示意。最小可用产品容器、长中文输入、真实多栏 FormCreate 与画布剩余空间需后续实测，不能把本页建议范围当作验收通过的产品支持范围。

主题样式应限定在组件实例内，真实弹层应跟随所属实例；禁止依赖修改宿主 `html/body/:root` 实现换肤。本页独立样稿不证明实例隔离、第三方弹层归属或卸载清理已经成立。

## 7. 框架适配约束与映射

本章为初稿 01 的第 1 轮规范修订，依据 2026-11-02 用户明确要求补充；R2 只按配色来源与密度决定修正相关行。**映射候选已核对当前源码；真实主题适配尚未验证**。本章与[可机读映射](framework-mapping.json)均是设计资料，不是产品配置、已实现的适配器或新增框架支持声明。

本章的“语义 → `--el-*`”写入映射只适用于品牌预设与宿主种子定制。组件默认的跟随宿主模式不写任何 `--el-*` 变量，只按 §6 读取宿主值；此时 FlowDuet 自有组件（节点、分支、面板反馈）消费派生的 `--fd-*` 角色，EP 与 FormCreate 控件保持宿主外观，仅由 size 上下文对齐密度。

### 7.1 当前基座与证据口径

ConfigProvider 是两档密度的首选入口，但现有 FormManager／FormDesigner／FormPreview 多处显式 `size="small"`，不会被外层默认值覆盖。designer 的 NodeDrawer／NodePropertyFields 未设 size，使用 EP default，因此现有界面同屏混用 24／32px。把这些显式 small 改为跟随密度设置会让 FormCreate 部分在舒适默认下变高，属于产品可见变化，须在真实适配切片中单独确认与验证。namespace 需要相应样式配合；不能单改 namespace 就宣称 FormCreate 内部 `.el-*` 选择器、全局组件注册或实例隔离已经解决。[ConfigProvider 文档](https://element-plus.org/en-US/component/config-provider.html)

当前八类菜单与实际控件的核对清单：文本／多行文本 → ElInput／textarea；数字 → ElInputNumber；单选 → `fc-radio` 包装的 ElRadioGroup／ElRadio；多选 → `fc-checkbox` 包装的 ElCheckboxGroup／ElCheckbox；下拉单选 → `fc-select` 包装的 ElSelect／ElOption；日期 → ElDatePicker；开关 → ElSwitch。基础栅格为 `fcRow` 与列布局，另核对表单标签和错误。**八类字段不等于八种 UI 框架**；组件名称映射已按当前渲染器 alias 与包装组件源码核对，真实主题、全部状态和弹层均未验收。三个 `fc-*` 包装控件需单独核对属性透传，不能当作在上层直接使用 EP 原生控件。

映射数据将 `menuName` 与持久化的 `ruleType`、`ruleProps` 分开记录。`ruleProps` 只用于区分此处讨论的形态，不是生成模板或完整 props 白名单；文本允许缺省、空或 text 形态。多行文本菜单名为 `textarea`，持久化规则必须是 `type="input"`＋`props.type="textarea"`；独立 `type="textarea"` 不在当前守卫的支持范围。包装源码中出现的按钮式单／多选、分组选项等分支仅登记为来源线索，不凭源码存在就认定为本项目已开放或已验收形态。

**既有配置优先级尚未定稿**。FC 默认标签为右置、宽 125px，`options.form` 会进入表单 props 与 style；已保存的显式 size、labelPosition、labelWidth、inline/style，以及字段或栅格的显式配置都可能改变呈现。样稿顶置标签与 32／24px 高度不是修改既有文档的迁移指令。当前保真底线是保留并往返已有配置，不能为统一皮肤清空、改写或静默忽略这些值，也不能以 !important 强制压过业务布局。主题只提供候选默认；默认与既有显式值冲突时的产品策略须另行确认、验证，当前不承诺每份历史表单都呈现为样稿。FormCreate 的嵌套表单与顶置标签 CSS 还含 22px、20px、8px、4px 等固定尺寸，必须与 ElFormItem 的密度入口分别核对。[表单配置说明](https://www.form-create.com/v3/element-ui/global.html)

项目入口见 [NodePropertyFields](../../../../packages/designer/src/components/NodePropertyFields.vue)、[FormManager](../../../../packages/form-create/src/components/FormManager.vue)、[FormDesigner](../../../../packages/form-create/src/components/FormDesigner.vue)、[FormPreview](../../../../packages/form-create/src/components/FormPreview.vue)、[菜单与配置](../../../../packages/form-create/src/components/designer-config.ts)、[运行时安装](../../../../packages/form-create/src/form-create-setup.ts)。
