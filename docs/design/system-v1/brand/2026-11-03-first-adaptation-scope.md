## 首批交付对象

### 节点属性抽屉

通过现有公开 `DingtalkDesigner` 使用抽屉，不把内部 `NodePropertyFields` 新增为公开组件。覆盖当前可达对象：审批节点名称、单签审批人／多人审批人集合、四种完成方式、节点表单；抄送名称与收件人；条件分支名称与条件表达式；发起／结束打开后的无可配置字段状态；抽屉标题、正文及确定／取消操作。

节点表单保留当前两种形态：传目录时为原生 select（继承默认、目录选项与目录外引用），未传目录时为手写 formKey 输入。原生 select 不替换成 ElSelect；其系统弹出选项可控的外观限制须据真实浏览器登记，不为像素一致性更换交互。

保持当前抽屉、编辑缓冲、确定／取消、键盘操作与既有错误通道合同，不新增流程属性面板、并行分支配置入口或业务校验。抽屉外的流程默认表单选择器、节点卡片、分支块、连接线和画布不在换肤范围；它们仅作为真实入口及回归环境使用。选定局部通过不表示整套 DingtalkDesigner 已完成主题适配。

### FormCreate 表单预览

通过现有公开 `FormPreview`，覆盖当前文本、多行文本、数字、单选、多选、下拉单选、日期、开关；多行文本仍使用 `input + props.type=textarea` 的既有规则。日期仅覆盖当前开放的 date／datetime／week／month／year 单值形态及真实可达时间子面板，不增加范围、多值或新的字段能力。

包括预览表面、标签、必填／错误等真实可达状态、项目自有提示与操作按钮，以及实际出现的下拉／日期／时间弹层。不新增只读模式、字段能力或业务校验，不因基础库存在其他形态就扩大覆盖。

表单设计器外壳、配置面板、FormManager／FormDesigner 工具条与其服务式确认弹层不在本批。保留既有 rules/options、默认值、试填数据及设计文档边界；切主题不写回业务定义。

## 配置与集成合同

- 新适配显式启用；启用后默认跟随宿主，也可显式选品牌预设。浅深主题、舒适默认与紧凑档、运行中切换均在本批；宿主任意种子定制和其他自定义配置能力不自动纳入。
- 两处入口可在现有 designer／form-create 包边界内独立消费。公共外观职责沿用 designer，不新增主题包或工作台包，不让 core 增加 UI 依赖；具体实现接缝留待规格审阅。
- 同页实例可以使用不同配置，至少验证同一 Vue app 内双实例；各自弹层、内容／遮罩（如存在）、焦点和清理跟随所属实例。跟随宿主时不写入宿主的 EP 变量；品牌预设只影响所选实例区域及其所属弹层，不切换宿主 html/body 主题，不改无关宿主控件。
- 运行中切换配色来源、浅深主题与密度时，保留属性输入缓冲、预览试填值及中文输入；实际可达弹层在切换中的归属、焦点与关闭行为需实测，不能通过静默重建丢输入实现换肤。
- [ADR-0012](../../../adr/0012-component-appearance-and-opt-in.md)只记录默认配色与显式启用的长期取舍。公开 API 名称、类型、配置读取／继承、错误反馈与弹层机制仍须后续规格提案审阅；设计 tokens JSON 不是公开 API。
