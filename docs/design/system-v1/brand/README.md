## 维护与状态

`tokens.json` 是本批设计值的来源；样稿内 `#design-tokens` 保存同一份 JSON 的离线快照，便于直接打开。主色衍生角色与跟随宿主的中性派生值不手改：修改种子或参数后运行 `node docs/design/system-v1/brand/derive-palette.mjs --write` 重写派生值并同步快照，用 Prettier 格式化后再以 `--check` 校验；不得只改样稿中的颜色。标志从现有资产目录引用，不复制或重绘母版。

`componentMappings` 是主要语义索引，并非全部状态的完整依赖清单；具体框架候选见 `framework-mapping.json`。R1 原始统计保留在历史核对记录中，审查修正使用单独证据，不能把旧统计当作新增映射的验收。

初稿内部检查和修正不算用户修订轮次。初稿交付后，按用户汇总意见最多进行 2 轮集中修订；R1 完成框架映射补充，R2 落实两层结构、32／24px 密度与种子派生，**2 轮已全部用完**。仍有分歧则交付已有结论，重新决定投入，不自动追加。用户已于 2026-11-03 批准 R2 设计值，批准范围见[本轮决定](2026-11-02-decisions.md#用户批准)；此后修改设计值属于新的变更，需要重新审阅。

后续适配需另行明确切片与授权，消费对应的宿主隔离、编辑保真和空间证据。冻结事项以 [10 月 25 日收尾裁定](../../2026-10-25-stage-zero-closeout-inventory.md) 为准；本次恢复范围只覆盖本目录记录的设计工作。
