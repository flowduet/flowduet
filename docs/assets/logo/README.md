# LOGO 资产

「一树两冠」：纵向节点链主干 = 共享的 BPMN 模型树 / 仿钉钉审批流；左右双冠 = 同一棵树的两种视图投影。双色即 Duet 的两个声部：靛蓝 `#2D3E97` / 珊瑚橙 `#F76547`，中缝沿中轴分色。设计决策与被否决的备选见 [ADR-0008](../../adr/0008-logo-visual-identity.md)。

| 文件 | 用途 |
|---|---|
| `icon.svg` | 矢量母版（透明底；节点圆心经 mask 镂空） |
| `icon-1024.png` | 母版位图（GitHub 组织头像等方形容器） |
| `icon-512.png` / `icon-192.png` | 应用图标 / README 引用 |
| `icon-64.png` / `icon-32.png` / `icon-16.png` / `favicon.ico` | 小尺寸与站点图标 |
| `social-preview.png` | 仓库社交分享卡（1280×640） |

## 使用注意

- 节点圆心是**镂空透底**（SVG mask 实现），深浅主题下均无白色残留；不要给圆心加白色实心。
- `icon.svg` 内每条 path 的几何归一化于原点、由 `transform` 定位，手工挪动坐标会破坏结构。
- 正式修改流程：改位图定稿 → vtracer 分色描摹（保留 transform）→ 三条白色路径搬入 mask 挖孔 → 渲染比对验证。不要手改描摹产物。
- AI 生成草稿不入库，本目录是唯一品牌资产源。
