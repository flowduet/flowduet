# ADR-0001：项目定位与价值主张

- 状态：Accepted
- 日期：2026-09-14

## 背景

2026 年流程设计器生态三股势力：

1. **bpmn-js 封装派**：MiyueFE/bpmn-process-designer、温良恭版、Adminhcf 版及各 ruoyi 系脚手架——Vue2 时代代码居多，类型质量差，单视图；
2. **仿钉钉递归组件派**：wflow 等——交互贴近国内用户，但模型不是 BPMN 2.0，接引擎靠有损转换层；
3. **图库自绘派**：AntV X6 / LogicFlow（如 SimFlow）。

"**双模式共享一棵模型树 + Vue3/TS 严格类型 + 引擎无关适配器**"的组合没有公认成熟方案——这是本项目的机会缝隙。

## 决策

1. 定位：**开源社区项目**；
2. 价值标准：**被 npm install 才算价值，star 不算**；
3. 投入承诺：每周 ≥10 小时，或 2 人搭伙；v1 现实预期 4–6 个月；
4. 差异化三支点：双视图共享同一棵模型树（差异化核心）、TypeScript-first、引擎无关适配器。

## 被否决的定位

- 公司内部/商业产品落地：受众最硬但非本项目场景；
- 可售卖商业组件/SaaS：License、盗版、竞品定价，国内环境难度最高；
- 纯学习/技术研究：不欠用户，但放弃了真实反馈循环。

## 后果

- 一切取舍以"第一批真实集成用户"为准绳；
- 开源隐形税：每周投入中 2–3 小时属于 issue / 文档 / demo，需在预算内留出；
- 反面判词（自我警醒）：若做成"又一个 bpmn-js 封装"或"又一个 wflow"，项目失去存在意义。
