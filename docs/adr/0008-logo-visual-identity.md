# ADR-0008：视觉标识（LOGO）——一树两冠

- 状态：Accepted
- 日期：2026-09-20

## 背景

项目需要与定位匹配的视觉标识（命名见 [ADR-0007](0007-delivery-and-naming.md)）。AI 文生图迭代两轮概念（「双声部交织线」「一树两冠」）后，「一树两冠」定稿。位图不能直接当品牌资产，需矢量化；期间否决了手绘重绘路线（目测坐标重绘是再创作而非还原，像素差异率不可接受），确定对定稿位图算法描摹（vtracer）的路径，并解决其「几何原点归一化 + transform 定位」「stacked 分层致镂空失效」两个结构问题。

## 决策

1. 图形：**一树两冠**——纵向节点链主干对应共享 BPMN 模型树 / 仿钉钉审批流，左右双冠对应同一棵树的两种视图投影，双色对唱即 Duet 两个声部；
2. 配色：靛蓝 `#2D3E97` / 珊瑚橙 `#F76547`，中缝沿中轴分色；
3. 资产形态：SVG 母版（vtracer 分色描摹，节点圆心以 mask 镂空）+ 多尺寸 PNG + favicon + 1280×640 社交卡，存放于 [`docs/assets/logo/`](../assets/logo/README.md)。

## 被否决的备选

- **双声部交织线概念**：简洁但呈「数据交换」通用感，隐喻不如一树两冠精准；
- **手绘矢量重绘**：目测坐标重绘还原度低（本质是再创作），弃用；
- **跟随 bpmn.io 生态配色（橙绿）**：放弃自有识别度，且用户已确认当前配色定稿。

## 后果

- `icon.svg` 的 path 几何归一化于原点、由 transform 定位，圆心为 mask 镂空——手工改几何易破坏结构，修改一律走「位图定稿 → 分色描摹 → 重建 mask」流程；
- 白色从标志中消失（圆心透底），深浅主题下均无白色残留；
- 组织头像、社交卡、README 引用均出自本套资产，后续品牌场景不再另起炉灶。
