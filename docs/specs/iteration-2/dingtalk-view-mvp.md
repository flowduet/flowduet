# Spec：钉钉式视图 MVP（递归组件 + 抽屉 + playground 宿主）

- 状态：**成稿**（2026-09-20；prototype 结论 A + grilling R4/R5 折入，拆票依据）
- 原型依据：分支 `prototype/iter2-vertical-layout-mi`（deriveBlockTree / verticalDiLayout / demo 观感验收）
- 域术语：CONTEXT.md「钉钉式视图」「投影」「审批节点」节全部术语
- 上游约束：ADR-0003（双视图架构）、ADR-0004（钉钉式边界）

## Problem Statement

钉钉式用户（列表加节点、抽屉里配置的心智）没有可用的设计界面：内核能力就位但没有视图，「双视图共享一棵模型树」的立项主张（ADR-0003）至今无代码证据。

## Solution

designer 包提供钉钉式编辑视图：纵向递归组件渲染块树、右侧抽屉配置节点；**一切编辑直接调用模型树方法，变更后重推导渲染树**——无中间状态、无双向同步。playground 最小页面作为验收宿主。

## User Stories

1. 作为审批流配置者，我想在纵向列表里添加审批节点，这样不学画布就能建流程。
2. 作为审批流配置者，我想点开节点在抽屉里配置，这样上下文不离开列表。
3. 作为审批流配置者，我想给审批节点配一名或多名审批人，这样单签多人场景都覆盖。
4. 作为审批流配置者，我想多人时选完成方式（会签/或签/依次），这样不用懂多实例就能表达。
5. 作为审批流配置者，我想添加条件分支块并给每条支路配条件表达式，这样按条件走不同路。
6. 作为审批流配置者，我想把某条支路设为默认，这样其余情况有路可走。
7. 作为审批流配置者，我想添加并行分支块，这样支路同时推进。
8. 作为审批流配置者，我想添加抄送节点选收件人，这样相关人被知会。
9. 作为审批流配置者，我想给节点改名、删除节点/支路/块，这样改错不用重建。
10. 作为审批流配置者，我想切到 BPMN 只读视图看同一流程，这样能按画布心智审阅。
11. 作为审批流配置者，我想导出 XML 并部署到 Flowable，这样流程真实可跑。
12. 作为宿主开发者，我想挂一个模型实例就得到可编辑视图，这样集成成本是组件级。
13. 作为宿主开发者，我想视图无独立状态，这样不存在视图与模型失同步的事故面。
14. 作为产品演示者，我想 playground 双击即看，这样演示不搭环境。

## Implementation Decisions

- **绑定方式：直接读写 + 重推导**（grilling R4）——视图调 `BpmnModel` 方法增删改，变更后 `deriveBlockTree(model)` 重推导渲染树。不用响应式代理（穿不透 moddle 私有状态与登记表），不用 UI 树主据 + 提交回写（两套状态违反投影原则）。
- **渲染依据 = 块树**：`deriveBlockTree` 从内核公开导出（原型结论），与竖排坐标推导共用同一棵块树；组件按块类型递归——顺序段、条件块（互斥支路）、并行块（同时支路）。
- **几何**：视图建模不传坐标（`shape`/`waypoints` 可选化后），XML 导出经 `verticalDiLayout()` 落 DI；恒等布局遇缺坐标节点抛错兜底诚实。
- **抽屉字段面**（迭代二既定）：节点名、审批人 + 完成方式三档、条件表达式、默认分支开关、抄送收件人、formKey 占位；每次读写直接落模型字段。
- **技术栈**：Vue 3 + Element Plus（抽屉、表单控件、弹层开箱即用）。
- **视觉方向**（2026-09-20 出图定稿）：着色容器式分支块——浅靛蓝圆角容器 + 左侧竖轨 + 小标签表达条件/并行嵌套，卡间「+」插入按钮；抽屉为分段选项卡式——字段纵向分段，完成方式三张可选卡片（会签/或签/依次），多人时该段出现。靛蓝 `#2D3E97` 主导钉钉式视图（双色声部之一）。方向澄清图见 `docs/assets/design/iteration-2/`（AI 方向稿，非像素规格；组件面以 EP 实组件为准）。
- **插入语义**：加节点 = 当前节点之后；块内加支路 = 块尾追加；删除块 = 整块连支路移除。
- **playground 三区**：钉钉式编辑 | BPMN 只读 | XML 导出预览。
- **接缝**（grilling R5）：designer 只暴露一条顶层组件接缝（编辑组件 + 只读组件 + 导出入口），内部组件不外漏。

## Testing Decisions

- 视图行为以 playground **手验清单**验收（导出 → 6.8 部署是硬出口标准）；自动化只做「操作后块树反映正确」的一致性冒烟（外部行为级，不做像素断言）。
- 内核侧由三条测试链覆盖，视图不新增内核接缝。
- 先例：原型 demo.html 的观感验收方式（SVG 渲染 + 结论表，双击即看）。

## Out of Scope

BPMN 可编辑画布、监听器/扩展属性高级面板、表单绑定协议（仅 formKey 占位字段）、节点拒绝语义、撤销重做、多人协同、块折叠记忆、移动端适配。

## Further Notes

竖排布局器（`verticalDiLayout`）正式化落 core 的 layout 模块（与恒等布局并列），designer 只消费 `deriveBlockTree`——该跨包边界对只读投影 spec 同样适用；`shape` 可选化是内核唯一配合改动。
