# Spec：BPMN 视图只读投影（Vue-Flow）

- 状态：**成稿**（2026-09-20；prototype 结论折入，拆票依据）
- 原型依据：分支 `prototype/iter2-vertical-layout-mi`（vertical-scenario.xml + demo 观感）
- 上游约束：ADR-0003（同一棵模型树的两种投影，互切零转换）

## Problem Statement

双视图主张「一棵树、两种投影、互切零转换」目前只有钉钉式一侧在建；熟悉 BPMN 自由画布的用户没有查看入口，主张缺第二种呈现的代码证据。

## Solution

Vue-Flow **只读**画布作为模型树的第二种呈现：几何直读 DI 登记表（`shapeOf`/`waypointsOf`），与钉钉式视图共享同一模型实例，切换 = 换组件、不换模型。

## User Stories

1. 作为 BPMN 老手，我想在自由画布里查看钉钉式建的流程，这样按 BPMN 心智审阅结构与条件。
2. 作为 BPMN 老手，我想缩放平移画布，这样大流程也能看清局部。
3. 作为 BPMN 老手，我想元素有标准视觉词汇（事件圆、任务矩形、网关菱形、多实例标记），这样一眼认出元素类型。
4. 作为审批流配置者，我想两视图切换后内容一致，这样不怀疑背后有两份数据。
5. 作为审批流配置者，我想连线走向与折线和导出 XML 一致，这样画布不是另一套渲染。
6. 作为宿主开发者，我想只读组件与编辑组件可独立挂载，这样能只嵌预览不嵌编辑。
7. 作为产品演示者，我想同一页面切换两视图演示，这样双视图卖点一目了然。

## Implementation Decisions

- `@vue-flow/core` 自定义节点按 BPMN 元素类型渲染**经典词汇 + 现代化呈现**（2026-09-20 出图定稿）：圆角描边、柔和阴影、现代排版；珊瑚橙 `#F76547` 作声部强调色（多实例标记等），不配小地图（见 Out of Scope）；**不做**卡片化任务与着色分区（BPMN 老手零学习成本优先）。澄清图见 `docs/assets/design/iteration-2/bpmn-readonly-canvas.png`（AI 方向稿，非像素规格）。
- **几何零计算**：`shapeOf`/`waypointsOf` 直映射；钉钉式建的节点几何来自竖排布局器的产出（与 XML 导出同源，不另算一套）。
- **切换 = 组件切换**：两视图挂同一模型实例；互切后 XML 导出不变（零转换的证据形态）。
- **只读边界**：连线创建、节点拖拽、增删、编辑全部禁用（`@vue-flow` 只读配置清单进实现票，逐一核验）。
- **砍序第一位**：本 spec 超期时最先砍，独立性设计——被砍不阻塞其他出口标准，钉钉式编辑 → XML 导出 → 部署链路不受影响。

## Testing Decisions

- **互切一致性**（手验清单）：两视图挂同一实例，任意编辑后切换，呈现与 XML 导出一致。
- 不做画布像素级自动化（MVP 口径）；XML 与几何的一致性由内核三条链保证。
- 先例：原型 demo.html 的 SVG 直染观感（Vue-Flow 版为其正式化）。

## Out of Scope

画布编辑（拖拽/连线/增删）、DI 拖拽持久化、泳道、迷你地图、对齐线、自动布局交互调整、打印/导出图片。

## Further Notes

砍序语境：迭代二超期时按「只读投影 → 依次审批 → 抄送」顺序砍（总纲既定）；本 spec 被砍时多实例 spec 的 sequential 档不受牵连（二者独立）。
