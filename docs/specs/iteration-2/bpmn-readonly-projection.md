# Spec：BPMN 视图只读投影（Vue-Flow）

- 状态：**骨架**——拆票前成稿
- 所属包：`packages/designer`
- 上游依据：ADR-0003（DI 布局是独立模块；BPMN 视图 = 同一棵模型的另一种投影）

## 目标

Vue-Flow 只读画布作为模型树的第二种呈现：几何直读 DI 登记表（`shapes` / `waypoints`），与钉钉式视图读写**同一棵模型树实例**，互切零转换——以最低成本验证「一棵树、两种投影」的完整主张。

## 已定决策

- **只读**：本迭代不做画布编辑（拖拽、连线、增删节点全部留后，砍序中排第一位）；
- 几何来源：`BpmnModel` 的 `shapeOf` / `waypointsOf` 直映射，不经任何布局计算；
- 与钉钉式切换 = 切换视图组件，不切换/转换模型（ADR-0003 核心决策的代码证据）。

## 待细化（成稿时逐项钉死）

1. `@vue-flow/core` 接入：自定义节点组件按 BPMN 元素类型渲染（事件圆圈、任务矩形、网关菱形、多实例标记等最小视觉词汇）；
2. 连线渲染：`waypoints` 直映射；无坐标节点（钉钉式新加）依赖竖排坐标推导（见钉钉式视图 spec 待细化第 1 条）；
3. 切换交互：tab / 按钮形态，切换时模型实例保持不变；
4. 只读边界的技术保障：禁用画布交互事件的最小配置清单。

## 验收要点

- 与钉钉式视图互切，两侧呈现同一模型状态，无需任何转换步骤；
- XML 导出（含 `bpmndi`）与画布呈现一致；
- 被砍时不阻塞其余出口标准（砍序第一位，独立性设计）。
