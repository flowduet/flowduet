# Spec：并行网关 + 排他网关默认分支

- 状态：**骨架**——拆票前成稿
- 所属包：`packages/core`（模型 / 编译 / 解析 / 适配器 / DI）
- 域术语：见 CONTEXT.md「并行分支」「条件分支」

## 目标

内核支持并行网关与排他网关默认流转，承载钉钉式视图的并行分支块与「其余情况」默认支路；导出 XML 经 Flowable 6.8 部署冒烟验证。

## 已定决策

- 并行分支映射 `bpmn:ParallelGateway`；多条支路同时推进、全部汇合后继续；
- 默认分支进 MVP：排他网关的「其余情况」映射 `bpmn:ExclusiveGateway` 的 `default` 流转（钉钉心智高频必需）；
- 并行分支块在钉钉式视图的容器交互见视图层 spec，本 spec 只管模型面。

## 待细化（成稿时逐项钉死）

1. 模型 API：`addParallelGateway(spec)`；默认流转的表达方式——`SequenceFlowSpec` 增加默认标记 vs 网关侧 `defaultFlow` 引用（BPMN 语义上 default 是网关属性，建模接口怎么收敛）；
2. 校验规则：默认流转不得携带条件表达式；多实例（多入多出）网关的成对校验（分裂/汇合是否强制显式成对，还是允许隐式）；
3. 往返保真：`default` 属性在 `parse → compile` 的往返等价；
4. 基准文件：并行分裂-汇合最小流程一份、带默认分支的排他网关流程一份；
5. 与既有 `addExclusiveGateway` 的关系（默认分支是否回溯补 API）。

## 验收要点

- 编译合同：两份基准文件逐字一致；
- 往返保真：含默认流转与并行结构的语义等价；
- Flowable 6.8 部署冒烟通过。
