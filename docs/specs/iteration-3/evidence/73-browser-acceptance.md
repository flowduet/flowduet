# #73 Codex 内置浏览器功能验收（2026-09-28）

## 范围与环境

- 基线：`dbeaef3`（`feat/73-multi-form-override`），工作区干净；先执行 `pnpm build`，通过后启动 Playground：`pnpm --filter @flowduet/playground dev --host 127.0.0.1 --port 5199 --strictPort`。
- 浏览器：Codex In-app Browser，访问 `http://127.0.0.1:5199/`。通过页面按钮、表单、拖拽和文件选择器执行操作；DOM/AX 只用于读取实际结果，未直接改写页面状态。
- 使用真实 FormCreate 设计器拖入两个文本输入框：`form_3`（新版申请单）的“申请理由”为必填；`form_2`（复核单）的“复核意见”为普通文本。`form_1`（申请单）保持未绑定。
- 按本次请求，**A06 被引用表单的删除拒绝提示可见性不在本轮复核范围内**。准备的失效引用文件见 [`73-browser-fixtures/`](./73-browser-fixtures/)。

## 判定边界

- B02 是本轮真实浏览器复现的功能缺口；节点摘要对同名表单也只显示名称的静态评审发现仍成立，本轮未专门创建两个同名节点绑定来复测摘要。
- B09 仅证明页面保存动作完成、文件打开动作可用；**不证明下载文件内容与反复保存打开保真**。内置浏览器的下载取消不归类为 FlowDuet 产品缺陷。
- 本轮未重跑 Flowable 6.8 部署。其既有证据见 [`73-smoke-flowable68.txt`](./73-smoke-flowable68.txt)。
