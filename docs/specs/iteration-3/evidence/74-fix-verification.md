# #74 浏览器验收发现的修复复验（2026-09-29）

本记录接续 [`74-codex-browser-acceptance.md`](./74-codex-browser-acceptance.md) 的 F17 失败项与“取消”空白弹窗观察。首次验收结果保留原样；本文件只报告修复后的定向复验，不把尚未重跑的部分用例改记为通过。

## 修复范围

- 保存、打开共用的表单定义守卫现在拒绝字段/布局规则中的非空 `on`、`_on`、`nativeOn`、`computed`、`hook` 等脚本配置，也拒绝表单选项中的 `onSubmit` 等事件配置；空事件容器仍可往返。
- 对 FormCreate `parseJson` 会还原成函数的字符串编码做静态拒绝，包括提供者前后缀、`$FN:` / `$FNX:` / `$EXEC:` / `$GLOBAL:` 与原生 `function` 形式。下拉的 `remoteMethod` 即使未启用 `remote` 也拒绝。
- 表单内容编辑器的“取消”同时清除编辑态并关闭内层弹窗，不再留下空白“编辑表单”窗口。
