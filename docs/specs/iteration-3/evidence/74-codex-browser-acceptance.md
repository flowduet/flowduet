# #74 Codex 内置浏览器功能验收（2026-09-29）

## 结论

**本轮不能判定 #74 已通过功能验收。** 20 个产品用例中，11 个通过、8 个部分完成、1 个失败。失败项是 F17：字段事件 `on.change` 和表单选项 `onSubmit` 的脚本配置能随设计文档导入，界面显示“已打开设计文档”，未按 #74 的范围要求明确拒绝。另有一项独立交互问题：内容编辑器点“取消”后留下空白弹窗，须再点关闭。

## 需要处理的发现

1. **#74 阻断项：脚本配置导入未收口。** 使用本文件附带的两份脚本夹具分别导入，`[data-test="doc-status"]` 均出现“已打开设计文档”，`doc-error` 为空。`form-schema.ts` 仅检查已列出的类型、形态、远程 `effect.fetch`、`control` 与布局；`parseFormOptions` 只检查 JSON 对象形状。当前证据证明**接受了范围外配置**，尚不声称脚本在预览中实际执行。修复后应同时覆盖字段事件和表单级事件的保存、打开拒绝路径。
2. **非阻断交互问题：“取消”留下空白编辑弹窗。** 在表单内容编辑器按“取消”后，内层弹窗标题退为“编辑表单”，内容消失但弹窗仍在，需再点右上角关闭。`FormManager.vue` 将 `@cancel` 接为 `editing = null`，未同步关闭 `editVisible`。该问题在本轮真实界面复现；建议单独修复并补组件交互测试。
3. **内置浏览器证据缺口。** Blob 下载事件未完成，F09/F10 无法用本轮下载物确认往返与试填隔离。可拖拽菜单在内置浏览器里命中不稳定，F02/F06 的“从零逐项新建及阻止嵌套拖入”没有形成可靠通过证据。这些限制与上述产品缺陷分开记录；此前其他浏览器/自动化结果不能自动替代本轮通过。
