## D01 / U64：同 ID 文档重开后当前值区与可见字段不一致（P2）

稳定复现：打开 S1 → 预览经理审批并试填 → 切合同会签再切回经理，字段重置为设计默认 → 关闭预览 → 重新打开 S1（节点及表单 ID 相同）→ 再打开经理审批预览。可见申请人是“设计默认申请人”，但“当前值”区为 `{}`。切另一审批目标再切回来后，当前值区才恢复完整默认值。

预期：当前值展示应与本次真实渲染表单一致。实际：没有错误提示，但当前值区为空，会使使用者误判默认值或试填状态；影响重复打开同 ID 设计的验收闭环。**不是数字0或布尔false丢失**：U09/U14 的保存数据和可见字段都已通过。
